낚시 기록·추천 앱

현위치를 찍으면 날씨·물때가 자동으로 들어가고, 어종·사이즈·마릿수·채비를 체크하면 기록이 쌓이는 앱. 기록은 스코어와 포인트가 되고, 쌓인 데이터로 다음 출조지와 예상 포인트를 추천한다.

1. 범위와 단계 2. 페르소나 3. 유저 시나리오 4. 예외 시나리오 5. 화면 흐름 6. 화면별 와이어프레임

1. 범위와 단계

1차에서는 기록·추천·포인트 적립까지. 포인트 사용과 이벤트는 2차.

1차 — 이번 작업

  • 카카오·네이버 간편가입
  • 현위치 기반 자동 입력 (날짜, 날씨, 기온, 바람, 물때, 만조·간조)
  • 조과 체크 기록 (어종, 사이즈, 마릿수, 방법, 미끼, 사진, 꽝)
  • 금어기·금지체장 경고와 방생 기록
  • 사진 인증 → 포인트 적립 (잔액 표시, 적립 내역)
  • 유저별 스코어, 어종별 최대어, 배지
  • 다음 출조지 추천, 예상 포인트 히트맵
  • 주변 화장실·식당·편의점·낚시점·주차

2차 — 나중에

  • 포인트샵: 미끼 교환 (제휴 낚시점 바코드 쿠폰)
  • 이벤트 응모와 추첨, 쿠폰함
  • 동호회 그룹 랭킹
  • 사진 자 인식(사이즈 자동 측정)
1차에서 포인트는 "쌓이기만" 한다. 사용처가 없어도 잔액과 적립 내역은 보여주고, 포인트샵 탭 자리는 "준비 중"으로 비워둔다. 2차에서 사용처가 열려도 1차에 쌓인 포인트는 그대로 쓸 수 있다는 점을 가입 시 안내한다.

2. 페르소나

세 명의 사용자를 기준으로 시나리오를 쓴다.

민수 · 34세 · 입문 2년차방파제·갯바위 루어. 어디 가야 잡히는지 몰라 매번 유튜브를 뒤진다. 추천 기능의 주 사용자.
정호 · 52세 · 20년 경력선상·찌낚시. 수첩에 조과를 적어 왔다. 기록을 쌓고 실력을 비교하고 싶다. 스코어·최대어 기록의 주 사용자.
지은 · 41세 · 가족 동반아이와 함께 간다. 화장실·식당·주차가 조과만큼 중요하다. 주변 편의시설의 주 사용자.

3. 유저 시나리오

출조 전 → 현장 → 출조 후 순서. 각 시나리오 끝의 번호는 대응하는 와이어프레임 화면이다.

시나리오 0. 간편가입 1차

  1. 민수가 앱을 처음 열면 카카오로 시작 / 네이버로 시작 버튼 두 개만 보인다. 이메일 가입은 없다.
  2. 카카오를 누르면 카카오 로그인 → 동의 → 바로 홈으로 이동한다.
  3. 홈 진입 후 1회만 닉네임과 선호 낚시 방법을 묻는다. 건너뛰기 가능.
  4. 가입 없이 둘러보기를 누르면 날씨·물때·추천만 볼 수 있고, 기록과 포인트는 로그인을 유도한다.

→ 화면 1

시나리오 1. 다음 출조지 추천 1차

  1. 금요일 밤, 민수가 홈에서 이번 주말 어디 갈까?를 누른다.
  2. 앱이 민수의 과거 기록(선호 어종·방법·이동 거리), 주말 예보와 물때, 다른 유저의 최근 공개 조황, 꽝 기록을 종합한다.
  3. 추천 카드 3개가 뜬다. 예: "영흥도 진두항, 9물로 물때 좋음, 최근 3일 우럭 12건, 차로 1시간 10분, 화장실 50m".
  4. 카드를 누르면 포인트 상세로 들어간다.

→ 화면 2, 3

시나리오 2. 포인트 상세 — 물때·금어기·편의시설 1차

  1. 상세 화면 상단에 예상 포인트 히트맵(최근 조과 밀집도)이 보인다. 공개 설정된 기록만, 좌표 대신 반경으로 표시해 개인 포인트가 노출되지 않게 한다.
  2. 그 아래 해당 날짜의 물때, 만조·간조 시각, 예보, 추천 채비가 있다.
  3. 이 시기 잡으면 안 되는 어종 블록에 금어기 어종과 금지체장이 미리 표시된다. 예: "감성돔 25cm 미만 방생, 대구 금어기 1/16~2/15".
  4. 주변 화장실·편의점·식당·낚시점까지의 거리가 한 줄로 보인다.
  5. 출조 일정 저장을 누르면 전날 저녁에 예보와 함께 알림이 온다.

→ 화면 4

시나리오 3. 현장에서 조과 기록 1차

  1. 토요일 아침, 민수가 방파제에 도착해 현위치 찍기를 누른다.
  2. GPS로 위치를 잡고 다음 항목이 자동으로 채워진다: 날짜·시간, 날씨, 기온, 풍향·풍속, 물때, 만조·간조 시각, 수온. 자동 입력 영역은 점선 박스로 구분해 "내가 안 쳤는데 들어간 값"임을 보여준다.
  3. 체크 방식으로 조과를 입력한다.
    • 어종: 자주 잡는 어종이 앞에 오는 칩. 없으면 + 로 검색
    • 사이즈: cm 직접 입력 또는 슬라이더
    • 마릿수: − / + 버튼
    • 낚시 방법: 찌 / 원투 / 루어 / 선상 / 에깅
    • 미끼: 갯지렁이 / 크릴 / 웜 / 메탈지그 등
  4. 한 마리도 못 잡은 날은 꽝으로 기록을 누른다. 꽝도 추천 정확도에 쓰이는 데이터다.
  5. 통신이 안 되는 곳이면 임시 저장했다가, 연결되면 날씨·물때를 자동 보정한다.

→ 화면 5

시나리오 4. 금어기·금지체장 경고 1차

  1. 민수가 어종에서 감성돔, 사이즈에 22cm를 넣는다.
  2. 저장 전에 바텀시트가 올라온다: "감성돔 22cm는 방생 대상이에요 — 금지체장 25cm 미만". 금어기 어종이면 금어기 기간을 함께 보여준다.
  3. 선택지는 두 개. 방생하고 기록 남기기(+30P) 또는 어종 다시 선택.
  4. 방생 기록을 택하면 조과가 아닌 방생으로 저장되고, 스코어와 포인트에 보너스가 붙는다. 규정을 지키는 쪽이 이득이 되게 설계한다.

→ 화면 6

시나리오 5. 사진 인증과 포인트 적립 1차

  1. 체크를 마치고 다음: 사진 인증을 누르면 카메라가 열린다. "물고기와 자를 함께 찍어주세요" 가이드가 뜬다.
  2. 저장 전 앱이 두 가지를 확인한다.
    • 체크값 5개(어종·사이즈·마릿수·방법·미끼)가 모두 입력됐는가
    • 사진 EXIF의 촬영 시각·위치가 지금 기록과 맞는가
  3. 둘 다 통과하면 적립 예정 내역이 보인다: 기본 기록 20P + 사진 인증 30P + 첫 방문 포인트 10P = 60P.
  4. 저장하고 60P 받기를 누르면 기록 카드가 생기고 잔액이 1,240P → 1,300P로 바뀐다.
  5. 사진을 건너뛰면 기록은 저장되지만 포인트는 0P. "사진 없이 저장하면 포인트가 적립되지 않아요"를 미리 보여준다.

→ 화면 7, 8

시나리오 6. 스코어 확인 1차

  1. 정호가 출조를 마치고 내 기록 탭을 연다.
  2. 이달 스코어, 월별 그래프, 어종별 최대어(PB), 배지가 보인다.
  3. 스코어 산식: 마릿수 + 사이즈 가중치 + 어종 난이도 + 방생 보너스 + 출조 꾸준함.
  4. 포인트와 스코어는 다르다. 포인트는 쓰는 재화, 스코어는 실력 지표라서 포인트를 써도 스코어는 줄지 않는다.

→ 화면 10

시나리오 7. 주변 편의시설 1차

  1. 지은이 아이와 낚시 중 주변 탭을 누른다.
  2. 화장실(거리, 개방 시간, 장애인 화장실 여부), 식당(영업 중 여부), 편의점, 낚시점, 주차장이 지도에 표시된다.
  3. "가족 동반" 필터로 화장실·그늘막·주차가 가까운 포인트만 골라 본다.

→ 화면 9

시나리오 8. 포인트샵 — 미끼 교환 2차

  1. 정호가 1,300P를 모아 포인트샵에 들어간다.
  2. "크릴 1kg 쿠폰 800P"를 교환하면 바코드 쿠폰이 발급된다.
  3. 제휴 낚시점 지도에서 가까운 매장을 골라, 출조 당일 바코드를 보여주고 수령한다. 배송 없음.

→ 화면 11 (2차)

시나리오 9. 포인트샵 — 이벤트 응모 2차

  1. 지은이 이벤트 탭에서 "선상 우럭 출조 1인권, 응모 100P, 마감 10/20, 당첨 3명"을 본다.
  2. 100P로 응모하면 응모 완료와 추첨일이 표시된다.
  3. 추첨일에 푸시 알림으로 결과를 받고, 당첨 시 쿠폰함에 들어온다.

→ 화면 11 (2차)

4. 예외 시나리오

현장은 통신과 GPS가 불안정하고, 포인트가 걸리면 가짜 기록이 생긴다.

5. 화면 흐름

번호는 6장의 와이어프레임 화면 번호.

단계흐름
가입1 간편가입 → 2 홈
출조 전2 홈 → 3 추천 → 4 포인트 상세(물때·금어기·편의시설) → 일정 저장 → 전날 알림
현장2 홈 [현위치 찍기] → 5 조과 기록 → (6 금어기 경고) → 7 사진 인증 → 8 저장·적립
어디서든 9 주변 탭
출조 후8 저장 → 10 내 기록·스코어 → 공개 설정 시 4의 히트맵에 반영 → 3 추천 엔진 입력
2차11 포인트샵 (미끼 교환 · 이벤트 응모)
